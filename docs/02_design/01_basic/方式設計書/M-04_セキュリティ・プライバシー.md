## 1. 概要
本アプリはサーバーを持たず、認証もなく、データは iPhone 内にのみ保存する。そのため一般的なWebシステムに比べて守る対象は少ないが、以下の点について対策を定める。

| 守る対象 | 想定するリスク |
|---------|--------------|
| 利用者のデータ（服の情報・写真） | 外部への送信、写真に含まれる位置情報の残存 |
| アプリ本体 | 不正なスクリプトの実行、改ざんされた外部ファイル・依存パッケージの混入 |

## 2. 対策

### 2.1 データを外部に送信しない
- アプリは外部のサーバー・サービスと通信しない（アクセス解析、広告、外部フォント、CDN などを使わない）
- 通信は、アプリ本体を公開先から取得するときのみとする
- ログは開発者コンソールにのみ出力し、送信しない（処理設計書 共通 10章）

### 2.2 写真の位置情報を残さない
- iPhone で撮影した写真には、撮影場所の位置情報（GPS）などの付加情報が含まれる場合がある
- 写真の取り込み（処理設計書 P-04）では画像を描き直して JPEG に変換するため、付加情報は保存する画像に引き継がれない。これにより、位置情報を端末内にも保存しない
- テストで、保存した画像に位置情報が含まれていないことを確認する（テスト方針書）

### 2.3 不正なスクリプトの実行を防ぐ
- 画面への表示は React の仕組みで行い、入力された文字列を HTML として解釈させない（`dangerouslySetInnerHTML` は使わない）
- コンテンツセキュリティポリシー（CSP）を設定し、アプリ本体以外のスクリプト・通信を禁止する。公開先でHTTPヘッダーを設定できない場合があるため、HTML の `meta` タグで設定する

| 項目 | 設定 | 意味 |
|------|------|------|
| default-src | 'self' | 原則としてアプリ本体からのみ読み込む |
| script-src | 'self' | スクリプトはアプリ本体のもののみ |
| img-src | 'self' blob: data: | 画像はアプリ本体と、端末内で作った画像のみ |
| style-src | 'self' 'unsafe-inline' | スタイルはアプリ本体のもの（画面部品が使う直接指定を許可） |
| connect-src | 'self' | 通信はアプリ本体の公開先のみ |
| worker-src | 'self' | Service Worker はアプリ本体のもののみ |
| object-src | 'none' | プラグイン等は禁止 |

### 2.4 依存パッケージの管理
- 使うパッケージは処理設計書 共通 3章のものに限り、追加する場合は理由を設計書に記載する
- `package-lock.json` で版を固定し、CIでは `npm ci` で同じ版をインストールする
- 公開前に `npm audit` で既知の脆弱性を確認し、重大なもの（high 以上）がある場合は対応してから公開する

### 2.5 通信の暗号化
- 公開先は HTTPS で配信する（GitHub Pages・Cloudflare Pages とも標準で HTTPS）

## 3. 本アプリで対象外とするもの

| 項目 | 理由 |
|------|------|
| 認証・アクセス制御 | 利用者は本人のみで、データは本人の iPhone 内にしかない（要件定義書 2.2） |
| データの暗号化保存 | iPhone 本体のロック（パスコード・Face ID）による保護に委ねる |
| サーバーのセキュリティ対策 | サーバーを持たない |
