## 2. 共通仕様

### 2.1 認証方式
Spring Securityによるトークンベース認証（JWT）とする。API-001（新規登録）・API-002（ログイン）を除く全APIは、リクエストヘッダーに有効なアクセストークンが必要。

- ログイン成功時（API-002）にアクセストークンを発行する
- 蔵書記録系API（API-004〜API-008、API-009）は、トークンから解決したユーザー自身の記録のみを操作対象とする

### 2.2 共通リクエストヘッダー

| ヘッダー名 | 必須 | 説明 |
|-----------|------|------|
| Authorization | ○（API-001, API-002を除く） | `Bearer <アクセストークン>` の形式で指定 |
| Content-Type | ○（リクエストボディを伴う場合） | `application/json` |

### 2.3 共通エラーレスポンス形式
```json
{
  "error": {
    "code": "＜エラーコード＞",
    "message": "＜エラーメッセージ＞"
  }
}
```

### 2.4 共通エラー（全API共通）

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 401 | UNAUTHORIZED | Authorizationヘッダーが未指定、またはトークンが無効・期限切れ |
| 500 | INTERNAL_ERROR | サーバー内部エラー |

## 3. エンドポイント詳細

### API-001: ユーザー新規登録

- **概要**: メールアドレスとパスワードで新規アカウントを作成する（画面設計書 SC-002 会員登録画面に対応）
- **メソッド／パス**: `POST /api/auth/register`

#### リクエスト

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|-------------|------|----|------|------|
| email | body | string | ○ | メールアドレス。メールアドレス形式であること |
| password | body | string | ○ | パスワード。8文字以上、英字と数字を含むこと |

#### レスポンス（成功時: 201）
```json
{
  "id": 1,
  "email": "user@example.com"
}
```

#### エラーレスポンス

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 400 | VALIDATION_ERROR | メールアドレスの形式が不正、またはパスワードが要件を満たさない（画面設計書 ERR-005） |
| 409 | EMAIL_ALREADY_EXISTS | 指定したメールアドレスが既に登録されている（画面設計書 ERR-003） |

### API-002: ログイン

- **概要**: メールアドレスとパスワードで認証し、アクセストークンを発行する（画面設計書 SC-001 ログイン画面に対応）
- **メソッド／パス**: `POST /api/auth/login`

#### リクエスト

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|-------------|------|----|------|------|
| email | body | string | ○ | メールアドレス |
| password | body | string | ○ | パスワード |

#### レスポンス（成功時: 200）
```json
{
  "accessToken": "＜JWT文字列＞",
  "user": {
    "id": 1,
    "email": "user@example.com"
  }
}
```

#### エラーレスポンス

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 400 | VALIDATION_ERROR | メールアドレス・パスワードが未入力（画面設計書 ERR-001） |
| 401 | INVALID_CREDENTIALS | メールアドレスとパスワードの組み合わせが一致しない（画面設計書 ERR-002） |

### API-003: 書誌情報検索

- **概要**: ISBNまたはタイトルで検索し、書誌情報候補を取得する（画面設計書 SC-004 書籍検索画面に対応）。qが10桁または13桁の数字（ハイフン可）の場合はISBNとみなしopenBD APIを検索し、それ以外はタイトルとみなし国立国会図書館サーチAPIを検索する（openBDはISBN検索のみでタイトル検索に対応しないため）
- **メソッド／パス**: `GET /api/books/search`

#### リクエスト

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|-------------|------|----|------|------|
| q | query | string | ○ | ISBN（10桁または13桁の半角数字、ハイフン可）またはタイトルの一部 |

#### レスポンス（成功時: 200）
```json
{
  "results": [
    {
      "isbn": "9784000000000",
      "title": "書籍タイトル",
      "author": "著者名",
      "publisher": "出版社名",
      "coverImageUrl": "https://example.com/cover.jpg"
    }
  ]
}
```
タイトル検索（国立国会図書館サーチ）の結果は表紙画像を取得できないため `coverImageUrl` はnullとなる。また対象資料にISBNが登録されていない場合は `isbn` もnullとなる。

#### エラーレスポンス

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 400 | VALIDATION_ERROR | 検索キーワードが未入力 |
| 404 | NO_SEARCH_RESULTS | 該当する書誌情報が見つからない（画面設計書 ERR-006） |
| 502 | EXTERNAL_API_ERROR | openBD API・国立国会図書館サーチAPIとの通信に失敗した（画面設計書 ERR-007） |

---

### API-004: 蔵書記録一覧取得

- **概要**: ログインユーザーの蔵書記録を一覧取得する。検索・絞り込み条件を指定可能（画面設計書 SC-003 蔵書一覧画面に対応）
- **メソッド／パス**: `GET /api/records`

#### リクエスト

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|-------------|------|----|------|------|
| keyword | query | string | - | タイトル・著者を対象とした部分一致検索 |
| genre | query | string（複数指定可） | - | ジャンルでの絞り込み |
| status | query | string | - | 読書ステータス（未読／読書中／読了）での絞り込み |
| page | query | integer | - | ページ番号（デフォルト: 1） |
| size | query | integer | - | 1ページあたりの件数（デフォルト: 20） |

#### レスポンス（成功時: 200）
```json
{
  "items": [
    {
      "id": 1,
      "isbn": "9784000000000",
      "title": "書籍タイトル",
      "author": "著者名",
      "coverImageUrl": "https://example.com/cover.jpg",
      "status": "読了",
      "rating": 5
    }
  ],
  "page": 1,
  "size": 20,
  "totalCount": 1
}
```
該当する蔵書記録が0件の場合は `items: []` を返す（画面設計書 ERR-011は画面側での空状態表示に用いる）。

#### エラーレスポンス

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 400 | VALIDATION_ERROR | page・sizeが不正な値（0以下、数値以外等） |

---

### API-005: 蔵書記録新規作成

- **概要**: 書誌情報に読書ステータス・読了日・感想・評価・ジャンルを付与して蔵書記録を作成する（画面設計書 SC-005 蔵書登録画面に対応）
- **メソッド／パス**: `POST /api/records`

#### リクエスト

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|-------------|------|----|------|------|
| isbn | body | string | ○ | ISBN |
| title | body | string | ○ | 書名 |
| author | body | string | - | 著者名 |
| publisher | body | string | - | 出版社名 |
| coverImageUrl | body | string | - | 表紙画像URL |
| status | body | string | ○ | 読書ステータス（未読／読書中／読了） |
| finishedDate | body | string（date） | statusが「読了」の場合○ | 読了日。本日以前の日付のみ |
| review | body | string | - | 感想。最大1000文字 |
| rating | body | integer | - | 評価（1〜5の整数） |
| genres | body | string[] | - | ジャンル・タグ |

#### レスポンス（成功時: 201）
```json
{
  "id": 1,
  "isbn": "9784000000000",
  "title": "書籍タイトル",
  "status": "読了",
  "finishedDate": "2026-08-01",
  "review": "面白かった",
  "rating": 5,
  "genres": ["小説"]
}
```

#### エラーレスポンス

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 400 | VALIDATION_ERROR | statusが未指定／statusが「読了」なのにfinishedDateが未入力（画面設計書 ERR-008）／finishedDateが未来日（画面設計書 ERR-009）／reviewが1001文字以上／ratingが1〜5の範囲外 |

### API-007: 蔵書記録更新

- **概要**: 指定した蔵書記録の読書ステータス・読了日・感想・評価・ジャンルを更新する（画面設計書 SC-007 蔵書編集画面に対応）
- **メソッド／パス**: `PUT /api/records/{id}`

#### リクエスト

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|-------------|------|----|------|------|
| id | path | integer | ○ | 蔵書記録ID |
| status | body | string | ○ | 読書ステータス（未読／読書中／読了） |
| finishedDate | body | string（date） | statusが「読了」の場合○ | 読了日。本日以前の日付のみ |
| review | body | string | - | 感想。最大1000文字 |
| rating | body | integer | - | 評価（1〜5の整数） |
| genres | body | string[] | - | ジャンル・タグ |

#### レスポンス（成功時: 200）
API-006と同形式のレスポンスボディを返す。

#### エラーレスポンス

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 400 | VALIDATION_ERROR | statusが「読了」なのにfinishedDateが未入力（画面設計書 ERR-008）／finishedDateが未来日（画面設計書 ERR-009）／reviewが1001文字以上／ratingが1〜5の範囲外 |
| 404 | RECORD_NOT_FOUND | 指定したIDの蔵書記録が存在しない、またはログインユーザーの記録ではない |

### API-009: 読書統計取得

- **概要**: 指定した年の読了冊数・ジャンル内訳等の統計を取得する（画面設計書 SC-008 読書統計画面に対応）
- **メソッド／パス**: `GET /api/stats`

#### リクエスト

| パラメータ名 | 位置 | 型 | 必須 | 説明 |
|-------------|------|----|------|------|
| year | query | integer | - | 集計対象年（未指定時は当年） |

#### レスポンス（成功時: 200）
```json
{
  "year": 2026,
  "totalCount": 12,
  "genreBreakdown": [
    { "genre": "小説", "count": 7 },
    { "genre": "ビジネス", "count": 5 }
  ]
}
```

#### エラーレスポンス

| ステータスコード | エラーコード | 発生条件 |
|-----------------|--------------|---------|
| 400 | VALIDATION_ERROR | yearが数値以外 |
