## 1. 本書の位置づけ
画面設計書で定義した各画面（SC-001〜SC-008）について、画面上の操作が「どのAPIを呼び出し」「処理設計書のどの処理フローに対応し」「結果を画面にどう反映するか」を定義する。バリデーションルール・エラーメッセージ本文は画面設計書（4〜6節）を参照。

## 2. SC-001 ログイン画面

| 画面操作 | 呼び出すAPI | 対応する処理（処理設計書） | 画面側の挙動 |
|---------|------------|---------------------------|-------------|
| ログインボタン押下 | API-002 | 3.1 F-001（ログイン） | 成功: アクセストークンを保存し SC-003 へ遷移／失敗: ERR-001（未入力）または ERR-002（認証失敗）をフォーム上部に表示 |
| 「新規登録はこちら」リンク押下 | なし（画面遷移のみ） | - | SC-002 へ遷移 |

## 3. SC-002 会員登録画面

| 画面操作 | 呼び出すAPI | 対応する処理（処理設計書） | 画面側の挙動 |
|---------|------------|---------------------------|-------------|
| 登録ボタン押下 | API-001 | 3.1 F-001（会員登録） | 成功: SC-001 へ遷移しログインを促すメッセージを表示／失敗: ERR-003（メール重複）または ERR-005（パスワード要件未達）を表示。ERR-004（確認用パスワード不一致）は送信前にクライアント側で検証しAPIを呼び出さない |

## 4. SC-003 蔵書一覧（本棚）画面

| 画面操作 | 呼び出すAPI | 対応する処理（処理設計書） | 画面側の挙動 |
|---------|------------|---------------------------|-------------|
| 画面表示時 | API-004 | 3.4 F-004／F-008 | 取得した一覧を本棚形式で表示。取得中はローディング表示 |
| キーワード／ジャンル／ステータスの変更 | API-004 | 3.4 F-004／F-008 | 条件を付与して再取得し、一覧を更新。0件時はERR-011相当の空状態メッセージを表示 |
| 「本を追加」ボタン押下 | なし（画面遷移のみ） | - | SC-004 へ遷移 |
| 本のカードをクリック | なし（詳細取得はSC-006側で実施） | - | SC-006 へ遷移（選択した蔵書記録IDをパスパラメータとして渡す） |
| 「統計を見る」リンク押下 | なし（画面遷移のみ） | - | SC-008 へ遷移 |
| 「ログアウト」ボタン押下 | なし（保存済みトークンの破棄のみ） | - | SC-001 へ遷移 |

## 5. SC-004 書籍検索画面

| 画面操作 | 呼び出すAPI | 対応する処理（処理設計書） | 画面側の挙動 |
|---------|------------|---------------------------|-------------|
| 検索ボタン押下 | API-003 | 3.2 F-002 | 成功: 検索結果をカード一覧で表示／ERR-006（0件）: 「該当する書籍が見つかりませんでした」を表示／ERR-007（外部API失敗）: 再試行を促すメッセージを表示 |
| 「戻る」ボタン押下 | なし（画面遷移のみ） | - | SC-003 へ遷移 |
| 検索結果カードの「この本を登録」ボタン押下 | なし（選択した書誌情報を保持して画面遷移） | - | SC-005 へ遷移（isbn, title, author, publisher, coverImageUrlを引き継ぐ） |

## 6. SC-005 蔵書登録画面

| 画面操作 | 呼び出すAPI | 対応する処理（処理設計書） | 画面側の挙動 |
|---------|------------|---------------------------|-------------|
| 画面表示時 | なし（SC-004から引き継いだ書誌情報を表示） | - | 書誌情報を読み取り専用で表示 |
| 「登録」ボタン押下 | API-005 | 3.3 F-003／F-006 | 成功: SC-003 へ遷移／失敗: ERR-008（読了日未入力）または ERR-009（読了日が未来日）をフォーム上に表示 |
| 「戻る」ボタン押下 | なし（画面遷移のみ） | - | SC-004 へ遷移（別の本を探す） |

## 7. SC-006 蔵書詳細画面

| 画面操作 | 呼び出すAPI | 対応する処理（処理設計書） | 画面側の挙動 |
|---------|------------|---------------------------|-------------|
| 画面表示時 | API-006 | 3.5 F-005（詳細取得） | 成功: 書誌情報・ステータス・読了日・感想・評価・ジャンルを表示／404: SC-003 へ戻す |
| 「編集」ボタン押下 | なし（画面遷移のみ） | - | SC-007 へ遷移 |
| 「削除」ボタン押下（確認ダイアログでOK後） | API-008 | 3.5 F-005（削除） | 成功: SC-003 へ遷移／ERR-010（削除失敗）: エラーメッセージを表示し画面に留まる |
| 「一覧に戻る」ボタン押下 | なし（画面遷移のみ） | - | SC-003 へ遷移 |

## 8. SC-007 蔵書編集画面

| 画面操作 | 呼び出すAPI | 対応する処理（処理設計書） | 画面側の挙動 |
|---------|------------|---------------------------|-------------|
| 画面表示時 | API-006（既存値の取得） | 3.5 F-005（詳細取得） | 取得した内容をフォームの初期値として表示 |
| 「更新」ボタン押下 | API-007 | 3.5 F-005（更新） | 成功: SC-006 へ遷移／失敗: ERR-008 または ERR-009 をフォーム上に表示 |
| 「キャンセル」ボタン押下 | なし（画面遷移のみ） | - | SC-006 へ遷移（変更内容は破棄） |
