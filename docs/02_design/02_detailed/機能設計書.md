## 1. モジュール構成

バックエンドはJava + Spring Bootによるレイヤードアーキテクチャとする。パッケージ構成は以下の通り。

```
com.example.bookrecord
├── controller      … REST APIエンドポイント（リクエスト受付・レスポンス組み立て）
├── service         … ビジネスロジック
├── repository      … Spring Data JPAによるデータアクセス
├── entity          … JPAエンティティ（DB設計書のテーブルに対応）
├── dto             … リクエスト／レスポンスDTO
├── client          … 外部API連携（openBD）
├── security        … Spring Security設定、JWT発行・検証
└── exception       … カスタム例外、共通例外ハンドラ（@ControllerAdvice）
```

- controller → service → repository の一方向依存とし、下位層は上位層を参照しない
- 外部API（openBD）連携は client パッケージに閉じ込め、service からのみ呼び出す
- 各機能の処理の流れ（呼び出し順序・分岐・例外時の挙動）は処理設計書を参照

## 2. クラス／関数設計

### 機能ID: F-001（ユーザー登録・ログイン）

| クラス／関数名 | 概要 | 入力 | 出力 |
|----------------|------|------|------|
| AuthController#register | 会員登録APIのエンドポイント（API-001） | RegisterRequest（email, password） | UserResponse |
| AuthController#login | ログインAPIのエンドポイント（API-002） | LoginRequest（email, password） | LoginResponse（accessToken, user） |
| AuthService#register | メールアドレス重複チェック、パスワードのハッシュ化、ユーザー保存 | email, password | User |
| AuthService#login | 認証、JWTトークン発行 | email, password | accessToken |
| UserRepository | usersテーブルへのCRUD | - | - |
| JwtTokenProvider | JWTの発行・検証 | User／トークン文字列 | トークン文字列／認証情報 |

### 機能ID: F-002（書誌情報検索・取得）

| クラス／関数名 | 概要 | 入力 | 出力 |
|----------------|------|------|------|
| BookController#search | 書誌情報検索APIのエンドポイント（API-003） | q（ISBNまたはタイトル） | BookSearchResponse |
| BookSearchService#search | 入力形式の判定（ISBN／タイトル）、OpenBdClientまたはNdlSearchClientの呼び出し、結果整形 | q | List\<BookSummary\> |
| OpenBdClient#findByIsbn | openBD APIへのHTTPリクエスト（ISBN検索専用） | ISBN | openBDレスポンス |
| NdlSearchClient#searchByTitle | 国立国会図書館サーチAPI（SRU, dcndl）へのHTTPリクエスト（タイトル検索専用、openBDがタイトル検索非対応のため使用） | タイトル | dcndl形式のXMLレスポンス |

### 機能ID: F-003（蔵書記録の新規作成）／ F-006（ジャンル・タグ付け）

| クラス／関数名 | 概要 | 入力 | 出力 |
|----------------|------|------|------|
| RecordController#create | 蔵書記録新規作成APIのエンドポイント（API-005） | CreateRecordRequest | RecordResponse |
| RecordService#create | 入力値検証（読了日・文字数・評価範囲）、ジャンルの取得または新規作成、保存 | CreateRecordRequest, userId | BookRecord |
| GenreService#findOrCreate | ジャンル名からGenreエンティティを取得、存在しなければ新規作成 | ジャンル名リスト | List\<Genre\> |
| BookRecordRepository | book_recordsテーブルへのCRUD | - | - |
| GenreRepository | genresテーブルへのCRUD | - | - |

### 機能ID: F-004（蔵書記録の一覧表示） ／ F-008（検索・絞り込み）

| クラス／関数名 | 概要 | 入力 | 出力 |
|----------------|------|------|------|
| RecordController#list | 蔵書記録一覧取得APIのエンドポイント（API-004） | keyword, genre, status, page, size | RecordListResponse |
| RecordService#search | 検索・絞り込み条件をもとにレコード取得、ページング | keyword, genre, status, page, size, userId | Page\<BookRecord\> |
| BookRecordRepository#search | JPA Specificationによる動的検索クエリ | 検索条件 | List\<BookRecord\> |

### 機能ID: F-005（蔵書記録の編集・削除）

| クラス／関数名 | 概要 | 入力 | 出力 |
|----------------|------|------|------|
| RecordController#get / #update / #delete | 詳細取得・更新・削除APIのエンドポイント（API-006, 007, 008） | id（path）、UpdateRecordRequest | RecordResponse／なし |
| RecordService#get | IDと所有ユーザーの一致を確認して1件取得 | id, userId | BookRecord |
| RecordService#update | 入力値検証、更新、ジャンル関連の張り替え | id, UpdateRecordRequest, userId | BookRecord |
| RecordService#delete | 所有ユーザー確認の上で削除 | id, userId | - |
