## 1. 概要

| 項目 | 内容 |
|------|------|
| テーブル名 | items |
| 論理名 | アイテム |
| 役割 | 登録した服1点ごとの情報を保存する。写真の画像は持たず、写真IDの並び（photoIds）で photos を参照する |
| 想定件数 | 当面100件、最大300件程度 |
| 関連テーブル | photos（1対1〜10）、subcategories（多対0..1）、カテゴリ・ベースカラー（アプリ内定数） |

## 2. テーブル定義

| カラム名 | 型 | NULL許可 | 主キー | 外部キー | 説明 |
|---------|----|---------|--------|---------|------|
| id | string | - | ○ | - | アイテムID（UUID） |
| name | string | - | - | - | 名前。1〜50文字 |
| categoryId | string | - | - | カテゴリ（定数） | カテゴリID（共通 5.1） |
| subcategoryId | string | ○ | - | subcategories.id | サブカテゴリID。未設定は null。categoryId と同じカテゴリのサブカテゴリであること |
| colorId | string | - | - | ベースカラー（定数） | ベースカラーID（共通 5.2） |
| brand | string | ○ | - | - | ブランド。1〜50文字 |
| size | string | ○ | - | - | サイズ。1〜20文字 |
| purchaseDate | string | ○ | - | - | 購入日。`YYYY-MM-DD` 形式。今日以前の日付 |
| price | number | ○ | - | - | 購入金額（円）。0〜9,999,999 の整数 |
| shop | string | ○ | - | - | 購入店舗。1〜100文字 |
| seasons | string[] | - | - | - | 季節コード（共通 5.3）の配列。未設定は空配列。重複なし、春→夏→秋→冬の順で保存 |
| material | string | ○ | - | - | 素材。1〜100文字 |
| washingMethod | string | ○ | - | - | 洗濯方法。1〜100文字 |
| memo | string | ○ | - | - | メモ。1〜1000文字。改行を含む |
| photoIds | string[] | - | - | photos.id | 写真IDの配列。1〜10件。配列の順が表示順で、先頭が代表写真 |
| createdAt | number | - | - | - | 登録日時（エポックミリ秒）。更新時は変更しない |
| updatedAt | number | - | - | - | 更新日時（エポックミリ秒） |

## 3. インデックス

| インデックス名 | 対象カラム | 種別 | 用途 |
|----------------|-----------|------|------|
| （主キー） | id | UNIQUE | アイテムの1件取得 |
| categoryId | categoryId | INDEX | カテゴリ別の件数取得 |
| subcategoryId | subcategoryId | INDEX | サブカテゴリ別の件数取得（SC-08）、削除可否の判定（DL-06） |
| createdAt | createdAt | INDEX | 登録日順の取得 |

- 一覧の絞り込み・並び替え（ベースカラー・季節・ブランド・購入日・購入金額・名前）は、全アイテム（最大300件程度）をメモリに読み込んでアプリ側で行う。件数が少なく、項目内OR・項目間ANDの組み合わせはインデックスでは扱いにくいため、これらの項目にはインデックスを作らない

## 4. 関連する操作

| 操作（共通 6章） | 内容 |
|-----------------|------|
| No.1 アイテム登録 | items に追加（photos・thumbnails と同一トランザクション） |
| No.2 アイテム更新 | items を更新（photos・thumbnails と同一トランザクション） |
| No.3 アイテム削除 | items から削除（photos・thumbnails と同一トランザクション） |
| No.7 サブカテゴリ削除 | subcategoryId インデックスで件数を確認（読取のみ） |
