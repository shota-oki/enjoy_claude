## 1. 概要

| 項目 | 内容 |
|------|------|
| テーブル名 | photos |
| 論理名 | 写真 |
| 役割 | アイテムの写真を、縮小・圧縮した画像として保存する。詳細表示（SC-04）で使う |
| 想定件数 | アイテム数×平均3枚（最大でアイテム数×10枚） |
| 関連テーブル | items（多対1）、thumbnails（1対1） |

## 2. テーブル定義

| カラム名 | 型 | NULL許可 | 主キー | 外部キー | 説明 |
|---------|----|---------|--------|---------|------|
| id | string | - | ○ | - | 写真ID（UUID） |
| itemId | string | - | - | items.id | 所属するアイテムのID |
| image | Blob | - | - | - | 画像データ。長辺1280pxに縮小したJPEG（画質0.8程度） |
| width | number | - | - | - | 縮小後の幅（px） |
| height | number | - | - | - | 縮小後の高さ（px） |
| byteSize | number | - | - | - | image のサイズ（バイト）。SC-06の保存容量の計算に使う |
| createdAt | number | - | - | - | 登録日時（エポックミリ秒） |

## 3. インデックス

| インデックス名 | 対象カラム | 種別 | 用途 |
|----------------|-----------|------|------|
| （主キー） | id | UNIQUE | 写真の1件取得 |
| itemId | itemId | INDEX | アイテム削除時に写真をまとめて取得・削除 |

## 4. 関連する操作

| 操作（共通 6章） | 内容 |
|-----------------|------|
| No.1 アイテム登録 | 写真ごとに追加 |
| No.2 アイテム更新 | 追加された写真を追加、取り除かれた写真を削除 |
| No.3 アイテム削除 | itemId インデックスで取得して削除 |
| No.9 保存容量の取得 | byteSize を合計 |

## 5. 備考
- 写真の並び順は photos 側には持たず、items.photoIds の配列の順で管理する
