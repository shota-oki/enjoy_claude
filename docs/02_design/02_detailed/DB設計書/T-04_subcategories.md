## 1. 概要

| 項目 | 内容 |
|------|------|
| テーブル名 | subcategories |
| 論理名 | サブカテゴリ |
| 役割 | カテゴリ（固定）ごとのサブカテゴリを保存する。ユーザーが追加・名称変更・削除・並び替えできる |
| 想定件数 | 初期50件、1カテゴリ最大30件 |
| 関連テーブル | items（0..1対多）、カテゴリ（アプリ内定数） |

## 2. テーブル定義

| カラム名 | 型 | NULL許可 | 主キー | 外部キー | 説明 |
|---------|----|---------|--------|---------|------|
| id | string | - | ○ | - | サブカテゴリID（UUID） |
| categoryId | string | - | - | カテゴリ（定数） | 所属するカテゴリのID（共通 5.1） |
| name | string | - | - | - | サブカテゴリ名。1〜20文字。同じカテゴリ内で重複不可 |
| sortOrder | number | - | - | - | カテゴリ内の表示順（小さいほど先）。連番である必要はない |
| createdAt | number | - | - | - | 登録日時（エポックミリ秒） |
| updatedAt | number | - | - | - | 更新日時（エポックミリ秒） |

## 3. インデックス

| インデックス名 | 対象カラム | 種別 | 用途 |
|----------------|-----------|------|------|
| （主キー） | id | UNIQUE | サブカテゴリの1件取得 |
| categoryId | categoryId | INDEX | カテゴリ別のサブカテゴリ取得 |
| [categoryId+name] | categoryId, name | UNIQUE | 同じカテゴリ内での名前の重複防止 |
| [categoryId+sortOrder] | categoryId, sortOrder | INDEX | カテゴリ内の表示順での取得 |

## 4. 関連する操作

| 操作（共通 6章） | 内容 |
|-----------------|------|
| No.4 サブカテゴリ追加 | 30件未満を確認し、sortOrder＝カテゴリ内の最大値＋10で追加 |
| No.5 サブカテゴリ名称変更 | name・updatedAt を更新 |
| No.6 サブカテゴリ並び替え | 2件の sortOrder を交換 |
| No.7 サブカテゴリ削除 | items の件数が0件であることを確認して削除 |
| No.10 初期サブカテゴリの投入 | 5章の初期データを登録 |

## 5. 初期データ
アプリの初回起動時（settings の `subcategoriesSeeded` が未登録の場合）に、要件定義書 5.3 の初期サブカテゴリを登録し、`subcategoriesSeeded` に true を保存する。以降はユーザーがすべて削除しても再投入しない。

| categoryId | 初期サブカテゴリ（sortOrder の順） |
|-----------|--------------------------------|
| tops | Tシャツ（半袖）、Tシャツ（長袖）、シャツ（半袖）、シャツ（長袖）、ポロシャツ、ニット・セーター、スウェット、パーカー、タンクトップ |
| bottoms | スラックス、デニム、チノパン、カーゴパンツ、ワイドパンツ、イージーパンツ、ショートパンツ |
| outer | テーラードジャケット、ブルゾン、レザージャケット、コート、ダウンジャケット、カーディガン、ベスト |
| setup | セットアップ、スーツ |
| shoes | スニーカー、革靴、ブーツ、ローファー、サンダル |
| bag | リュック、ショルダーバッグ、トートバッグ、ボディバッグ、ビジネスバッグ |
| hat | キャップ、バケットハット、ハット、ニット帽 |
| accessory | ベルト、ネクタイ、マフラー・ストール、手袋、腕時計、財布、アクセサリー |
| other | （なし） |

- sortOrder は各カテゴリ内で 10, 20, 30 … と10刻みで採番する（間に挿入しやすくするため）

## 6. 備考
- items はサブカテゴリを名前ではなくIDで参照するため、名称変更時に items の更新は不要
