## 1. 概要

| 項目 | 内容 |
|------|------|
| テーブル名 | settings |
| 論理名 | 設定 |
| 役割 | アプリの設定値をキーと値の組で保存する |
| 想定件数 | 数件 |
| 関連テーブル | なし |

## 2. テーブル定義

| カラム名 | 型 | NULL許可 | 主キー | 外部キー | 説明 |
|---------|----|---------|--------|---------|------|
| key | string | - | ○ | - | 設定キー（3章） |
| value | 任意 | - | - | - | 設定値 |

## 3. 設定キー一覧

| key | value の型 | 初期値 | 説明 |
|-----|-----------|--------|------|
| itemSortOrder | string | `created_desc` | SC-01の並び順（共通 5.4 の並び順コード） |
| subcategoriesSeeded | boolean | （未登録） | 初期サブカテゴリ（T-04 5章）を投入済みかどうか。投入後に true を保存する |

## 4. インデックス

| インデックス名 | 対象カラム | 種別 | 用途 |
|----------------|-----------|------|------|
| （主キー） | key | UNIQUE | 設定値の取得・保存 |

## 5. 関連する操作

| 操作（共通 6章） | 内容 |
|-----------------|------|
| No.8 並び順の保存 | itemSortOrder を更新 |
| No.10 初期サブカテゴリの投入 | subcategoriesSeeded に true を保存 |

## 6. 備考
- 並び順の設定は、ブラウザの localStorage ではなく本テーブルに保存する（保存先を IndexedDB の1か所にまとめるため）
