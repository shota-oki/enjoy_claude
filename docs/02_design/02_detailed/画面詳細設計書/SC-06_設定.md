## 1. 概要
設定タブの先頭画面。サブカテゴリ管理（SC-07）への入口と、アプリの情報（登録件数・保存容量・データの永続保存の状態・バージョン）を表示する。

## 2. 画面構成（上から順）

| 領域 | 内容 | 表示条件 | スクロール |
|------|------|---------|-----------|
| ナビゲーションバー | ボタンなし | 常時 | 固定 |
| タイトル | 「設定」 | 常時 | 縦スクロール |
| 分類 | 「サブカテゴリ管理」の行 | 常時 | 縦スクロール |
| アプリについて | 登録アイテム数、写真の保存容量、データの永続保存、バージョン | 常時 | 縦スクロール |
| 注意書き | データの保存先に関する説明 | 常時 | 縦スクロール |
| タブバー | 「設定」選択状態 | 常時 | 固定 |

## 3. 項目定義

| No | 項目 | 種別 | 表示内容・データ項目 | 表示形式 | 備考 |
|----|------|------|-------------------|---------|------|
| 1 | タイトル | ラベル | 「設定」 | ― | |
| 2 | 見出し | ラベル | 「分類」 | ― | |
| 3 | サブカテゴリ管理 | 行（右に「›」） | 「サブカテゴリ管理」 | ― | 行全体がタップ可能 |
| 4 | 見出し | ラベル | 「アプリについて」 | ― | |
| 5 | 登録アイテム数 | 項目 | 登録されているアイテムの件数 | 「16点」 | |
| 6 | 写真の保存容量 | 項目 | 保存している写真（一覧用の小さい画像を含む）の合計サイズ | 1MB未満：「1MB未満」／1GB未満：「約32.4MB」（小数第1位）／1GB以上：「約1.2GB」 | |
| 7 | データの永続保存 | 項目 | iPhoneがアプリのデータを自動削除しない設定になっているか | 「有効」／「未許可」 | 「未許可」の場合は行の下に「ホーム画面に追加して開くと有効になります。」を表示 |
| 8 | バージョン | 項目 | アプリのバージョン | 「1.0.0」 | |
| 9 | 注意書き | ラベル | 「データはこのiPhone内にのみ保存されます。Safariの履歴・Webサイトデータを削除すると、登録したデータも削除されます。」 | ― | |

## 4. イベント・処理

| No | イベント | 処理内容 | 遷移先 |
|----|---------|---------|--------|
| 1 | 画面表示 | 登録件数、写真の合計サイズ、永続保存の状態を取得して表示する。取得に失敗した項目は「―」と表示する | ― |
| 2 | サブカテゴリ管理をタップ | カテゴリ選択画面を表示する | SC-07 |
| 3 | 「クローゼット」タブ | 一覧へ移動する（一覧の条件は保持） | SC-01 |

- 永続保存の要求（自動削除しないようiPhoneに求める処理）は、アプリ起動時に毎回行う。本画面では結果の表示のみ行う
