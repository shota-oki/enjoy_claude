## 1. 概要
SC-01の上に下から重ねて表示するアクションシート。一覧の並び順を選択する。選択した時点で一覧に反映し、シートを閉じる。

## 2. 画面構成（上から順）

| 領域 | 内容 |
|------|------|
| 見出し | 「並び替え」 |
| 選択肢 | 並び順7種（現在の並び順にチェック表示） |
| キャンセル | 選択肢とは分けて最下部に表示 |

- 背後のSC-01は暗く表示する

## 3. 項目定義

| No | 項目 | 種別 | 表示内容 | 並び替えの内容 | 備考 |
|----|------|------|---------|--------------|------|
| 1 | 見出し | ラベル | 「並び替え」 | ― | |
| 2 | 登録日が新しい順 | 選択肢 | 同左 | 登録日時の降順 | 初期値 |
| 3 | 登録日が古い順 | 選択肢 | 同左 | 登録日時の昇順 | |
| 4 | 購入日が新しい順 | 選択肢 | 同左 | 購入日の降順 | 購入日未入力は末尾 |
| 5 | 購入日が古い順 | 選択肢 | 同左 | 購入日の昇順 | 購入日未入力は末尾 |
| 6 | 購入金額が高い順 | 選択肢 | 同左 | 購入金額の降順 | 購入金額未入力は末尾 |
| 7 | 購入金額が安い順 | 選択肢 | 同左 | 購入金額の昇順 | 購入金額未入力は末尾 |
| 8 | 名前順 | 選択肢 | 同左 | 名前の五十音順（英字は日本語の後） | |
| 9 | チェック | アイコン | 現在の並び順の選択肢に表示 | ― | |
| 10 | キャンセル | ボタン | 「キャンセル」 | ― | |

- 並び替えの値が同じアイテム同士は、登録日が新しい順に表示する（SC-01 5章）

## 4. イベント・処理

| No | イベント | 処理内容 | 遷移先 |
|----|---------|---------|--------|
| 1 | シート表示 | 現在の並び順の選択肢にチェックを表示する | ― |
| 2 | 選択肢をタップ | 選択した並び順を一覧に適用し、端末に保存する（次回起動時も引き継ぐ）。シートを閉じ、一覧を先頭までスクロールする。現在と同じ並び順を選んだ場合は閉じるだけとする | SC-01 |
| 3 | キャンセル／シートの外をタップ | 並び順を変えずに閉じる | SC-01 |
