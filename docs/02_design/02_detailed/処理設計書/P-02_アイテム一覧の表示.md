## 1. 概要
全アイテムを取得し、一覧の条件（カテゴリ・サブカテゴリ・絞り込み条件）と並び順に従って表示する。チップの件数、絞り込みシートの該当件数、ブランドの一覧もこの処理で計算する。

| 項目 | 内容 |
|------|------|
| 契機 | SC-01 の表示、条件・並び順の変更、DBの変更（登録・更新・削除） |
| 関連画面 | SC-01、SC-02 |
| 関連テーブル | items（読込）、thumbnails（読込）、subcategories（読込） |

## 2. 関数

| 関数名 | 概要 | 入力 | 出力 |
|--------|------|------|------|
| useItems | 全アイテムを取得し、DBが変更されたら自動で再取得する（`useLiveQuery`） | なし | Item[] |
| itemRepository.listAll | 全アイテムを取得する | なし | Item[] |
| listQuery.filter | 条件で絞り込む | Item[]、条件 | Item[] |
| listQuery.sort | 並び順に従って並べる | Item[]、並び順コード | Item[] |
| listQuery.countByCategory | カテゴリごとの件数を数える（カテゴリ・サブカテゴリ以外の条件を反映） | Item[]、条件 | Map（categoryId → 件数） |
| listQuery.countBySubcategory | 選択カテゴリ内のサブカテゴリごとの件数を数える（「未設定」を含む） | Item[]、条件 | Map（subcategoryId または未設定 → 件数） |
| listQuery.listBrands | 登録済みブランドを重複なく名前順で返す | Item[] | string[] |
| photoRepository.getThumbnails | 一覧用画像をまとめて取得する | photoId[] | Map（photoId → Blob） |
| useObjectUrl | Blob を表示用URLに変換し、不要になったら解放する | Blob | URL文字列 |

## 3. 処理フロー

### 3.1 一覧の表示
1. `useItems` で全アイテムを取得する
2. 条件に該当しなくなったブランドを、絞り込み条件から取り除く（SC-02 4章）
3. `listQuery.filter` で絞り込み、`listQuery.sort` で並べる
4. 表示するカードの代表写真ID（photoIds の先頭）について、`photoRepository.getThumbnails` で一覧用画像をまとめて取得し、表示用URLに変換して表示する
5. 表示対象が変わったとき、画面を離れるときは、不要になった表示用URLを解放する
6. SC-04 へ移動するときは、スクロール位置を ListStateContext に保存する。SC-04 から戻ったときは保存した位置に戻す

### 3.2 絞り込みの判定（listQuery.filter）
アイテムごとに以下をすべて満たす場合に表示対象とする（SC-01 6章）。
1. カテゴリが未選択、またはアイテムの categoryId が一致する
2. サブカテゴリが未選択、または一致する（「未設定」選択時は subcategoryId が null）
3. ベースカラー条件が空、またはアイテムの colorId が条件のいずれかに一致する
4. 季節条件が空、またはアイテムの seasons と条件に共通する季節が1つ以上ある
5. ブランド条件が空、またはアイテムの brand が条件のいずれかに完全一致する

### 3.3 並び替え（listQuery.sort）
1. 並び順コードに応じて比較する項目と昇順・降順を決める（DB設計書 共通 5.4）
2. 購入日・購入金額による並び替えでは、値が null のアイテムを末尾に置く
3. 比較結果が同じ場合は、登録日時の新しい順にする
4. 名前順は `compare.ts` の比較関数（五十音順、英字で始まるものは日本語の後）を使う

### 3.4 絞り込みシートの該当件数（SC-02）
1. シート内で選択中の条件と、SC-01 で選択中のカテゴリ・サブカテゴリを合わせて `listQuery.filter` を行い、件数を数える
2. 選択を変えるたびに再計算する（DBへの問い合わせはせず、取得済みのアイテムで計算する）

## 4. 例外処理

| 状況 | 対応 |
|------|------|
| アイテムの読み込みに失敗 | MSG-E12 を表示する（共通のエラー境界） |
| 一覧用画像が見つからない | そのカードは画像の代わりに灰色の枠を表示する（WARN ログ）。一覧全体の表示は続ける |
