## 1. 本書の方針
- 処理設計書は処理単位でファイルを分けて作成する。本書は全処理に共通する構成・方針（使用技術、層構成、ディレクトリ構成、状態管理、例外処理、ログ出力）を定める
- 画面の見た目や項目の仕様は画面詳細設計書、データ構造はDB設計書を正とし、処理設計書では重複して記載しない
- 各処理で新たに定めた仕様のうち確認が必要なものは、各ファイルの「確認事項」に記載する

## 3. 使用技術

| 区分 | 採用技術 | 用途 |
|------|---------|------|
| 言語 | TypeScript | 全ソースコード |
| UIライブラリ | React | 画面の構築 |
| ビルド | Vite | 開発サーバー・本番ビルド |
| 画面遷移 | React Router（HashRouter） | 画面のURL管理。GitHub Pages で再読み込みしても404にならないよう、URLの `#` 以降で画面を切り替える方式とする |
| DB操作 | Dexie.js、dexie-react-hooks | IndexedDBの操作。`useLiveQuery` によりDBの変更を画面へ自動反映する |
| PWA | vite-plugin-pwa | Service Worker の生成、ホーム画面追加用の設定（マニフェスト） |
| スタイル | CSS Modules | 画面・部品ごとのスタイル（クラス名の衝突を防ぐ） |
| テスト | Vitest、React Testing Library、fake-indexeddb | 単体テスト・結合テスト（IndexedDBはテスト用の代替実装を使う） |
| 静的解析 | ESLint、Prettier | コードの規約チェック・整形 |

## 4. レイヤ構成
処理を以下の層に分け、上の層から下の層のみを呼び出す。

| 層 | 役割 | 主なディレクトリ |
|----|------|----------------|
| 画面層 | 画面・シート・ダイアログの表示と、利用者の操作の受け付け。利用者への通知（メッセージの決定）もこの層で行う | `screens/`、`components/` |
| 状態層 | 画面をまたいで保持する状態（一覧の条件・スクロール位置等）とトースト・ダイアログの表示管理 | `state/`、`hooks/` |
| サービス層 | 入力チェック、絞り込み・並び替え、画像処理など、画面に依存しない処理 | `services/` |
| リポジトリ層 | DBの読み書き。トランザクションの単位はこの層で決める | `repositories/` |
| DB層 | スキーマ定義と初期データ投入 | `db/` |
| 共通 | 定数、型、表示形式の変換などの共通関数 | `constants/`、`types/`、`utils/` |

## 9. 例外処理方針

| 例外 | 発生箇所 | 捕捉する層 | 利用者への通知 |
|------|---------|-----------|--------------|
| DBを開けない・読み込み失敗 | 起動時、画面表示時 | 画面層（共通のエラー境界） | MSG-E12（ダイアログ） |
| 書き込み失敗（容量不足 QuotaExceededError を含む） | 登録・更新・削除・サブカテゴリ操作 | 画面層 | MSG-E11（ダイアログ）。画面と入力内容は保持する |
| 一意制約違反（サブカテゴリ名の重複） | P-07 | 画面層（DL-05） | MSG-E14（ダイアログ内） |
| InUseError（アイテムがあるサブカテゴリの削除） | P-09 | 画面層（DL-06） | 削除不可通知（MSG-C11・C12） |
| ImageLoadError（写真を読み込めない） | P-04 | 画面層（SC-05） | MSG-E10（トースト）。その写真だけ追加しない |
| 対象のアイテムが存在しない | SC-04・SC-05（編集）の表示時 | 画面層 | MSG-E13（トースト）を表示して SC-01 へ移動 |
| 想定外の例外 | 全体 | 画面層（共通のエラー境界） | MSG-E12（ダイアログ） |

- リポジトリ層・サービス層は例外を加工せずに上位へ伝え、利用者への通知は画面層で行う（メッセージの決定を1か所にまとめるため）
- 複数テーブルの更新はトランザクション内で行い、途中で失敗した場合はすべて取り消されるため、データが中途半端な状態にはならない

## 10. ログ出力方針
データは端末内のみで扱い外部へ送信しない方針（要件定義書 6章）のため、ログはブラウザの開発者コンソールにのみ出力し、保存・送信はしない。

| ログレベル | 出力対象 | 本番ビルドでの出力 |
|-----------|---------|------------------|
| ERROR | 想定外の例外、DBの読み書き失敗（例外の内容を含む） | 出力する |
| WARN | 写真の読み込み失敗、永続保存が許可されなかった、設定の保存失敗 | 出力する |
| INFO | 起動処理の開始・終了、初期データの投入 | 出力しない（開発時のみ） |
| DEBUG | 絞り込み条件・処理時間など開発時の確認用 | 出力しない（開発時のみ） |

- 利用者が入力した内容（名前・メモ等）や画像データはログに出力しない
