## 1. 概要
サブカテゴリの一覧を取得し、サブカテゴリの追加と名称変更を行う。

| 項目 | 内容 |
|------|------|
| 契機 | SC-07・SC-08 の表示、DL-05 で「追加」「変更」をタップ |
| 関連画面 | SC-07、SC-08（DL-05） |
| 関連テーブル | subcategories（読込・書込）、items（件数の読込） |

## 2. 関数

| 関数名 | 概要 | 入力 | 出力 |
|--------|------|------|------|
| useSubcategories | サブカテゴリを取得し、DBが変更されたら自動で再取得する | categoryId（省略時は全件） | Subcategory[] |
| subcategoryRepository.listByCategory | カテゴリのサブカテゴリを表示順で取得する | categoryId | Subcategory[] |
| subcategoryRepository.listAll | 全サブカテゴリを取得する（SC-07 の件数表示、SC-01・SC-04 の名称表示に使う） | なし | Subcategory[] |
| subcategoryRepository.add | サブカテゴリを末尾に追加する | categoryId、name | Subcategory |
| subcategoryRepository.rename | 名称を変更する | subcategoryId、name | なし |

## 3. 処理フロー

### 3.1 追加
1. SC-08 で「サブカテゴリを追加」をタップしたとき、表示中の件数が30件以上なら MSG-E15 を表示して終了する（DL-05 は表示しない）
2. DL-05 で名称を入力し「追加」をタップする（名称が空の間は押せない）
3. 名称の前後の空白を取り除く
4. 同じカテゴリ内に同じ名称があれば、MSG-E14 をダイアログ内に表示して終了する（ダイアログは閉じない）
5. `subcategoryRepository.add` を呼ぶ。トランザクション内で以下を行う
   1. 同じカテゴリの件数が30件未満であることを確認する
   2. カテゴリ内の sortOrder の最大値＋10（0件の場合は10）を sortOrder とする
   3. 採番したIDと現在日時を設定して追加する
6. 成功した場合：ダイアログを閉じ、MSG-I04 を表示する
7. 失敗した場合：一意制約違反なら MSG-E14 をダイアログ内に、その他は MSG-E11 を表示する（ダイアログは閉じない）

### 3.2 名称変更
1. DL-05 で名称を編集し「変更」をタップする
2. 名称の前後の空白を取り除く。変更前と同じ名称なら、何もせずダイアログを閉じる
3. 同じカテゴリ内に同じ名称（自分以外）があれば、MSG-E14 をダイアログ内に表示して終了する
4. `subcategoryRepository.rename` で name と updatedAt を更新する（items はIDで参照しているため更新しない）
5. 成功した場合：ダイアログを閉じ、MSG-I05 を表示する。SC-01・SC-04・SC-05 の表示は、DBの変更の自動反映により新しい名称になる
6. 失敗した場合：3.1 の手順7と同じ

## 4. 例外処理

| 状況 | 対応 |
|------|------|
| 名称の重複（事前チェックをすり抜け、一意制約で検出） | MSG-E14 をダイアログ内に表示する |
| 30件の上限を超える（別の操作で件数が増えていた等） | MSG-E15 を表示し、ダイアログを閉じる |
| 書き込みに失敗 | MSG-E11 を表示する（ERROR ログ） |
