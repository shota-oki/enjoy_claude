## 1. 概要
設定画面に表示するアプリ情報（登録アイテム数、写真の保存容量、データの永続保存の状態、バージョン）を取得する。

| 項目 | 内容 |
|------|------|
| 契機 | SC-06 の表示 |
| 関連画面 | SC-06 |
| 関連テーブル | items、photos、thumbnails（読込） |

## 2. 関数

| 関数名 | 概要 | 入力 | 出力 |
|--------|------|------|------|
| itemRepository.count | 登録アイテム数を数える | なし | number |
| photoRepository.totalByteSize | photos と thumbnails の byteSize を合計する | なし | number（バイト） |
| storageService.isPersisted | 永続保存の状態を取得する（`navigator.storage.persisted()`） | なし | boolean |
| format.byteSize | 容量を表示形式に変換する（SC-06 3章 No.6） | number（バイト） | 文字列（「1MB未満」「約32.4MB」「約1.2GB」） |

## 3. 処理フロー
1. 以下を並行して取得する
   1. `itemRepository.count` で登録アイテム数
   2. `photoRepository.totalByteSize` で保存容量
   3. `storageService.isPersisted` で永続保存の状態
2. 取得できた項目から順に表示する。保存容量は `format.byteSize` で表示形式に変換する
3. バージョンは、ビルド時に `package.json` のバージョンを埋め込んだ値を表示する
4. 永続保存が「未許可」の場合は、案内文（SC-06 3章 No.7）を表示する

## 4. 例外処理

| 状況 | 対応 |
|------|------|
| いずれかの取得に失敗 | その項目だけ「―」と表示する（WARN ログ）。他の項目の表示は続ける |
| 永続保存の状態を取得する機能に対応していない | 「未許可」と表示する |
