# docs ディレクトリについて

このディレクトリは、ウォーターフォール型の開発プロセスにおける各フェーズの成果物を格納します。

## 構成とフェーズの対応

| フェーズ | 格納先 | 成果物の例 |
|---------|--------|-----------|
| 全フェーズ共通 | `00_knowledge/` | 合意事項・変更履歴（ナレッジ） |
| 要件定義 | `01_requirements/` | 要件定義書 |
| 基本設計（外部設計） | `02_design/01_basic/` | 基本設計書、画面定義書、画面遷移図、方式設計書、API仕様書 |
| 詳細設計（内部設計） | `02_design/02_detailed/` | 機能設計書、処理設計書、画面詳細設計書、DB設計書 |
| テスト全体 | `03_test/` | テスト方針書 |
| 単体テスト | `03_test/01_unit/` | 単体テスト仕様書・結果 |
| 結合テスト | `03_test/02_integration/` | 結合テスト仕様書・結果 |
| システムテスト（総合テスト） | `03_test/03_system/` | システムテスト仕様書・結果 |
| 受入テスト | `03_test/04_acceptance/` | 受入テスト結果 |
| リリース・デプロイ | `04_release/` | リリース手順書 |
| 運用・保守 | `05_operation/` | 運用手順書、障害対応記録 |

## テンプレート

各ディレクトリには成果物のテンプレート（`＜成果物名＞_template.md`）を用意しています。実際の成果物を作成する際は、テンプレートをコピーして `_template` を外したファイル名（例: `要件定義書.md`）で保存し、内容を埋めてください。
