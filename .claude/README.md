# .claude ディレクトリについて

このディレクトリは、Claude Code がこのリポジトリで開発する際に使用する設定・拡張機能を格納します。

## 構成

```
.claude/
├── README.md          # このファイル
├── settings.json       # チームで共有する設定（権限・フックなど）。Gitにコミットする
├── settings.local.json # 自分専用の設定（モデル選択など）。Git管理対象外（作成時に自動でignore）
├── agents/              # サブエージェントの定義ファイルを置く場所
├── skills/               # カスタムスキル（SKILL.md）を置く場所
├── commands/            # カスタムスラッシュコマンドを置く場所
└── hooks/                # フックから呼び出すスクリプトを置く場所
```

## 各ファイル・ディレクトリの役割

- **settings.json**
  権限（`permissions`）やフック（`hooks`）など、チームで統一したい設定を記述します。Gitにコミットします。

- **settings.local.json**（未作成・必要に応じて追加）
  個人環境固有の設定を記述します。`.gitignore` により自動的にGit管理対象外になります。

- **agents/**
  特定のタスクに特化したサブエージェントを定義するディレクトリです。`Agent` ツールから呼び出せます。

- **skills/**
  `SKILL.md` を配置することで、`/スキル名` の形で呼び出せるカスタムスキルを定義できます。
  - `create-doc/`: `docs/` 配下のテンプレートをもとに、要件定義書・設計書・テスト仕様書・リリース手順書・運用手順書などの成果物を作成するスキル。

- **commands/**
  カスタムスラッシュコマンドを定義する従来形式のディレクトリです（新規追加は `skills/` を推奨）。

- **hooks/**
  `PreToolUse` / `PostToolUse` などのフックイベントから実行するスクリプトを配置します。実際のフック設定自体は `settings.json` 内の `hooks` セクションに記述します。

## 注意事項

`agents/`・`commands/`・`hooks/` は現時点では空（`.gitkeep` のみ）です。プロジェクトの開発が進み、サブエージェントやフックなどが必要になった段階で追加してください。
